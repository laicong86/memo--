# MemoTool v1.4

Windows 桌面托盘备忘录工具。基于 Python 3.9 标准库开发，单文件 exe，**运行时零第三方依赖**。

## v1.4 相对 v1.3 的更新

- **任务详情新增工作空间按钮**：详情标题旁「快速打开」直接打开绑定的工作空间目录，「绑定工作空间」可选择一个目录并随任务保存；未绑定或路径失效时给出温和提示。
- **详情改为紧凑各半布局**：展开详情不再额外加宽窗口，列表与详情各占约一半；用户拖动分隔条调整过的占比会被记住，重开详情原样恢复。
- **收起/展开态布局尺寸分别记忆**：关闭详情回到展开前的收起态尺寸，列表撑满不留白；缩窄后的窗口宽度在开关详情后保持不变（修复关详情列表被拉宽的问题）。
- **顶栏精简**：「仅显示已完成」并入排序下拉成为一个选项，排序与筛选可组合使用；「窗口保持最前」移入「设置」，可持久化并在启动 / 保存时即时生效；移除右上角多余的「×」按钮（隐藏到托盘仍可用「—」和全局热键）。
- **四角缩放修正**：窗口四角可自由拖动调整大小，圆角透明区也能抓住边缘。

## 主要功能

- 圆角卡片主窗口：实时搜索、排序 / 仅看已完成（下拉组合）、窗口保持最前（设置项）
- 详情面板：预期时间 / 紧急程度 / 状态 / 进度 / 工作空间编辑，历史进展倒序，**改动即自动保存**（400ms 防抖）
- 文本批量导入：`√` / `done` 表示完成，多个 `-` 分隔标题与进展说明，同标题自动更新不重复
- 系统托盘常驻、解锁提醒（含临期任务）、气泡提醒
- 全局快捷键：**F2** 呼出 / 最小化主窗口，**Ctrl+Alt+N** 快速新建（均可在设置中修改）
- 开机自动启动（当前用户级，可在设置里开关）
- 窗口边缘 8 方向自由缩放、四角拖动、空白区拖动、单实例互斥
- 应用图标已注入 exe、任务栏与系统托盘

## 下载与运行

下载附件 `MemoTool.exe` 直接运行即可，无需安装、无需 Python 环境。
运行数据保存在 `data/memos.json` 与 `data/config.json`，可通过 `MEMO_DATA_DIR` 重定向。

## 校验

发布资产的 SHA-256 可在下载后本地计算；仓库 `release/MemoTool.exe` 与 Release 附件为同一文件。
