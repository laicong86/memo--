# MemoTool v1.1

Windows 桌面托盘备忘录工具。基于 Python 3.9 标准库开发，单文件 exe，**运行时零第三方依赖**。

## v1.1 相对 v1.0 的更新

- **详情面板重排**：删掉顶部属性条的「预期完成时间」，日期框 / 时间框 / 日历按钮移到「创建时间」下方并以 `to` 标注；展开详情不再改变任务列表宽度，列表与详情之间新增可左右拖拽的分隔条调整占比。
- **时间输入更顺手**：时间框只填具体时间（如 `15:30`），留空默认按当天 `23:59:59` 保存；修复「先填时间、再选日期」时已填时间被覆盖的问题；日历弹窗改为在主体窗口附近弹出，多屏下不再到处找。
- **解锁临期提醒**：解锁时列出一天内将要超期的未完成任务，提醒阈值可在设置中调整。
- **双屏缩放修复**：窗口边缘拖拽缩放改为按窗口当前所在显示器的工作区计算，修复拖到副屏后尺寸被主屏钳制、位置被拉回的问题。

## 主要功能

- 圆角卡片主窗口：实时搜索、排序、仅看已完成、窗口保持最前
- 详情面板：预期时间 / 紧急程度 / 状态 / 进度编辑，历史进展倒序，**改动即自动保存**（400ms 防抖）
- 文本批量导入：`√` / `done` 表示完成，多个 `-` 分隔标题与进展说明，同标题自动更新不重复
- 系统托盘常驻、解锁提醒、气泡提醒
- 全局快捷键：**F2** 呼出 / 最小化主窗口，**Ctrl+Alt+N** 快速新建（均可在设置中修改）
- 窗口边缘 8 方向自由缩放，空白区拖动，单实例互斥
- 应用图标已注入 exe、任务栏与系统托盘

## 下载与运行

下载附件 `MemoTool.exe` 直接运行即可，无需安装、无需 Python 环境。
运行数据保存在 `data/memos.json` 与 `data/config.json`，可通过 `MEMO_DATA_DIR` 重定向。

## 校验

发布资产的 SHA-256 可在下载后本地计算；仓库 `release/MemoTool.exe` 与 Release 附件为同一文件。
